# سند — لكل حديث إسناد

**سند** أداة تحقق: تلصق نصًا يُنسب إلى النبي ﷺ، أو تكتب موضوعًا، فيخبرك سند هل هو موجود في الكتب الستة، وأين، وبأي لفظ. ثم يعرض كل طرقه في **شجرة إسناد تفاعلية**، من النبي ﷺ إلى المصنفين، ويعرض أحكام العلماء عليه **منسوبة إلى قائليها** كما وردت في الموسوعة الحديثية (الدرر السنية).

الذكاء الاصطناعي في سند **يبحث ويرتّب ويقارن** فقط. لا يؤلّف نصًا دينيًا، ولا يحكم على حديث أو راوٍ. كل معلومة دينية معها صندوق **«كيف حصلنا على هذه المعلومة؟»**: المصدر ورابطه، والنص الذي أُخذت منه حرفيًا، وتاريخ الأخذ، وطريقة الاستخراج، ودرجة الثقة. وإن لم يجد معلومة كتب **«غير متوفر في المصدر»**.

مشارك في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026** — المسار 04: أدوات المعرفة والتحقق.

## الحالة

النسخة 0 بُنيت قبل أيام التحدي (28 سبتمبر 2026) كنقطة بداية موثّقة. كل ما أُضيف بعدها مسجّل مرحلةً مرحلة في [CHANGELOG.md](CHANGELOG.md):

| المرحلة | ما أُضيف |
|---|---|
| 1 | مراجعة الكود وإصلاحه؛ قارئ أسانيد جديد (التحويل، الرواة المعطوفون، حذف الأفعال والكلمات الزائدة)؛ الإسناد في كل اسم؛ اختبارات |
| 2 | هوية بصرية كاملة (فاتح وداكن)، وإعادة بناء كل الصفحات |
| 3 | شجرة أقوى: ملء الشاشة، تكبير، خريطة مصغّرة، بحث عن راوٍ، تصفيات، مقارنة لفظ طريقين، حفظ صورة، رابط بحالة التصفية |
| 4 | أحكام العلماء منسوبة من واجهة الدرر السنية الرسمية؛ **تراجم الرواة من الدرر أُوقفت** لأن الوصول الآلي إليها غير مسموح |
| 5 | تقرير المصادر: `docs/PROVENANCE.md` وصفحة `/about/sources` |

القواعد التي يلتزمها كل تغيير: [`.claude/skills/religious-sourcing/SKILL.md`](.claude/skills/religious-sourcing/SKILL.md).

## كيف يعمل؟

```
نص المستخدم
   │  توحيد الكتابة العربية (حذف التشكيل، توحيد الهمزات…)
   ▼
بحث BM25 على المتون  ←  الكلمة غير الموجودة في المتون يُبحث بأقرب كلمة إليها (ويُقال ذلك للمستخدم)
   ▼
إعادة ترتيب: «التطابق المرتّب» = كم من كلمات النص وردت بالترتيب في نافذة واحدة من المتن
   (الكلمات النادرة أثقل وزنًا)
   ▼
الحالة:  موجود ≥ 0.85   |   قريب ≥ 0.70   |   غير موجود في مصادر سند
   ▼
صفحة الحديث: المتن، الإسناد بألفاظ التحديث ملوّنة، كل طرق الإسناد، الأحكام منسوبة إلى قائليها
   ▼
شجرة الطرق: روايات الحديث في الكتب الستة ← كل طرقها ← دمج من النبي ﷺ نزولًا ← نقطة تفرّع الطرق
```

**قراءة الإسناد** (`sanad_core/isnad.py`): قواعد مكتوبة تقسم النص عند ألفاظ التحديث، وتفصل الرواة المعطوفين بالواو، وتصل طرق **التحويل (ح)** فقط حيث يقول النص ذلك («كلاهما عن»، «كلهم عن»، أو اسم مشترك)، وما لا يتصل يبقى جزءًا منفصلًا لا يدخل الشجرة. كل اسم يحفظ الكلمات التي قُرئ منها.

**نقطة تفرّع الطرق (المدار):** الراوي الذي يمر به أكبر عدد من الطرق مضروبًا في عدد الفروع التي تخرج منه. في حديث «إنما الأعمال بالنيات» تظهر عند **يحيى بن سعيد الأنصاري**. هذا حساب، وليس حكمًا علميًا.

**الأحكام** (`sanad_core/dorar.py`): من واجهة الدرر السنية الرسمية فقط، بطلبات تعرّف نفسها ويفصل بينها 2.5 ثانية على الأقل، مخزنة مع تاريخ أخذها. تُعرض بحقول الدرر نفسها (المحدث، المصدر، الرقم، خلاصة الحكم) بنصها. المطابقة غير المؤكدة تُعرض «غير مؤكد» ولا يُختار منها شيء.

## التشغيل محليًا

```bash
# 1) الموقع (بايثون فقط، بدون مكتبات)
python serve.py                 # http://127.0.0.1:8000  (HOST=0.0.0.0 لإتاحته على الشبكة)
SANAD_DORAR_LIVE=0 python serve.py   # بدون أي طلب إلى الدرر السنية (المخزّن فقط)

# 2) الاختبارات
python -m unittest discover -s tests      # 67 اختبارًا، لا تتصل بالإنترنت (أو: python -m pytest tests)
python evaluation/run_eval.py             # تقييم البحث: recall@k وMRR والدقة، و«موجود» الخاطئ يجب أن يكون 0
python evaluation/build_cases.py          # إعادة بناء حالات التقييم (انظر evaluation/README.md)
python evaluation/parser_metrics.py       # مقاييس قراءة الأسانيد على كل المدونة

# 3) البيانات
python pipeline/reparse_chains.py         # إعادة قراءة الأسانيد بعد تعديل القارئ (بدون المدونة)
python pipeline/fetch_dorar_grades.py     # جلب أحكام الدرر لقائمة محدودة (واجهة رسمية، محدود السرعة)
python pipeline/gen_provenance.py         # توليد docs/PROVENANCE.md

# بناء البيانات من الصفر
pip install numpy scikit-learn
git clone --depth 1 https://github.com/ShathaTm/LK-Hadith-Corpus /tmp/lk
python pipeline/build_data.py /tmp/lk
```

## النشر

جاهز للنشر على **Vercel**: الواجهة في `public/` (وحدات ES بدون أدوات بناء)، والخادم دالة بايثون واحدة في `api/sanad.py` لا تحتاج مكتبة خارجية. `vercel.json` يضبط سياسة أمان المحتوى (CSP) وتوجيه المسارات.

## الحدود المعروفة

- المصادر: الكتب الستة فقط.
- **لا توجد تراجم للرواة.** الدرر السنية لا تتيح التراجم عبر واجهتها الرسمية، وصفحاتها محفوظة الحقوق ومحمية من الوصول الآلي؛ فتظهر حقول الترجمة «غير متوفر في المصدر». يعرض سند فقط ما تُظهره الأسانيد: الاسم كما ورد، وشيوخه وتلاميذه داخل الشجرة.
- أحكام الدرر مخزنة لـ 66 حديثًا؛ غيرها يُجلب عند فتح الصفحة (إن كان الجلب مفعّلًا).
- فصل الإسناد عن المتن آلي في غير البخاري (دقة نحو 92% حسب مصدر البيانات). الطرق التي لا يُذكر فيها النبي ﷺ بعد آخر راوٍ تُرسم بخط متقطع، والمقطوعة لا تُرسم.
- الأسماء القصيرة أو المشتركة، والمدموجة من صيغتين، والمبنية من إحالة («عن أبيه») تُعرض بإطار متقطع: دمجها غير مؤكد.
- حالات التقييم (22) استُخدمت لضبط العتبات، فليست اختبارًا مستقلًا.
